Esta sección está dedicada a todos aquellos con interés en las tecnologías y funcionamiento de la web, sea empresa, programador o un usuario muy curioso.

Tecnologías

Actualmente trabajo con diversas herramientas, entre ellas las más destacadas son Angular y Laravel que son los frameworks que usé para crear Cosymo. Esto es debido, a que soy desarrollador web Full-Stack y me puedo desenvolver en cualquier ámbito, cliente o servidor, eso me da mucha versatilidad a la hora de programar. En el caso de los lenguajes de programación, la plataforma está escrita en PHP (Laravel) y Typescript(Angular).

La base de datos de la plataforma utiliza SQL y como gestor de bases de datos relacional, MySQL.

Para el control de versiones trabajo con Git e incluyo mi propio CI/CD tanto en cliente como en servidor. Mantengo mi propio servidor web (VPS) y está configurada en Nginx.

A mayores, introducí una pasarela de pagos con Stripe mediante su API para los planes gratuitos y premium.

Por último, necesitaba mantener un almacenamiento de imágenes y vídeos fiable asi que opté por Cloudinary.
